1. System Context Diagram Breakdown (Page 169)

  • Central System Hub (CWTSCONNECT): Kinakatawan ng madilim na navy-blue circle sa gitna ang buong computing core ng CWTSConnect platform na nagpoproseso at nagko-coordinate ng lahat ng transaksyon.
  • USERS Entity (Naka-pwesto sa Ibaba): Nagpapadala ng user actions / submissions patungo sa central hub (login credentials, student skill profile, CMO requirements, community assistance requests, at coordinator administrative overrides).
  • FRONTEND Entity (Naka-pwesto sa Kanan-Itaas): Nakikipag-ugnayan sa pamamagitan ng bidirectional API requests / responses gamit ang RESTful endpoints at WebSocket real-time state broadcast.
  • NOTIFICATIONS Entity (Naka-pwesto sa Kanan-Ibaba): Tumatanggap ng email/alerts trigger para sa automated verification notices, deployment roster updates, at DTR attendance warnings.
  • DSS ENGINE Entity (Naka-pwesto sa Taas): Nagpapadala at tumatanggap ng matching algorithms / deployment events upang kalkulahin ang proximity score gamit ang Haversine distance formula at matching weight analysis laban sa skills ng estudyante at pangangailangan ng komunidad.
  • AUTH Entity (Naka-pwesto sa Kaliwa-Itaas): Nagpapatupad ng auth tokens / validation gamit ang secure HttpOnly session cookies, cryptographic token verification, at role-based access control (RBAC).
  • ACCOUNTS DB Entity (Naka-pwesto sa Kaliwa-Ibaba): Namamahala sa persistent account read/write operations sa Supabase PostgreSQL relational schema.

2. Data Flow Diagram Architectural Breakdown (Page 170)

  • USER Tier: Kinakatawan ng student volunteer, NSTP/CWTS coordinator, at community official na nag-a-access sa kani-kanilang designated web views gamit ang modern desktop/mobile web browsers.
  • FRONTEND Tier (Browser Client): Nagre-render ng dynamic UI/UX gamit ang vanilla CSS, semantic HTML5, at asynchronous JavaScript. Nagpapadala ng HTTPS/TLS encrypted network requests.
  • Load Balancer / Edge Tier: Responsable sa HTTPS/TLS termination, reverse proxy routing, CORS filtering, at security hardening (Helmet headers) bago maipasa ang trapiko sa backend.
  • BACKEND Tier (Express.js Container): Binubuo ng anim (6) na dedikadong functional subsystem:
    • API Gateway / Auth / Static Files: Request dispatcher, session validation, at web asset serving.
    • DSS Matching Engine: Real-time multi-factor algorithmic matchmaking na nagkakalkula ng Haversine distance at skill-compatibility matrix.
    • CMO Compliance & Verification: Tagasuri ng CHED CMO requirements (medical certificate, parent consent/waiver, barangay clearance).
    • Admin & Community Requests: CRUD services para sa community request proposals at coordinator approvals.
    • Attendance & Hours Tracking: Pamamahala sa 54-hour mandatory DTR logs na may coordinator audit protection.
    • 360 Evaluation & CHED CMO Reporting: Pagsusuri ng quantitative ratings at awtomatikong pagbuo ng standardized accomplishment reports.
  • DATABASE Tier (Supabase PostgreSQL): 3D cylinder representation ng ACID-compliant relational database para sa users, community profiles, deployment records, attendance logs, at metrics.
  • NOTIFICATION Tier: Asynchronous alert engine gamit ang SMTP email dispatchers at webhooks para sa agarang anunsyo sa mga estudyante at komunidad.
  • Cloudinary Object Storage Tier: Secure cloud bucket para sa encrypted upload at streaming ng mga opisyal na CMO waiver documents at geo-tagged attendance photos.
