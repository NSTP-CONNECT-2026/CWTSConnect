Displaying: System Boundary & Actor Use Case Associations

Mga Detalye ng Proposed Use Case Diagram (Thesis / Manuscript):

  • System Boundary: Kinakatawan ng malaking rectangular boundary ang CWTSConnect System kung saan nakapaloob ang lahat ng functional use cases na nakagrupo ayon sa functional modules.
  • Mga Aktor (Actors):
    • Student Volunteer (<<primary actor>>): Registration, Profile & Skills, CMO document uploads, Matched deployment viewing, Attendance monitoring (54 hours), at 360-degree evaluation rating.
    • Community Partner (<<primary actor>>): Portal access, Profile & site location management, Community project requests, Volunteer roster tracking, Daily Time Record (DTR) logging, at student performance evaluation.
    • CWTS Coordinator (<<administrator>>): Executive dashboard, User accounts management, CMO compliance auditing, Community proposal approvals, DSS matching execution, Deployment publishing, DTR log auditing, CHED CMO report generation, at system configuration.
    • Internal Subsystems (<<internal system / service>>): DSS Matching Engine (kalkulasyon ng proximity at skill compatibility) at Notification Service (awtomatikong alerto sa mga estudyante at partner).
  • UML Stereotypes:
    • <<include>>: Ginagamit kapag mandatory ang sub-process (hal. DSS Matching kasama ang Proximity Score at Skill Fit; Generate Reports kasama ang Issue Certificates; Log DTR kasama ang Track Rendered Hours).
    • <<extend>>: Ginagamit kapag may conditional branch (hal. Flag for Resubmission kung may kulang na CMO documents; Request Proposal Revision kung may kailangang baguhin sa community request).
  • Format at File Locations: Nakahanda ang ultra-crisp 300 DPI PNG (3800x2450 px), lossless Vector SVG, at Draw.io (.drawio) sa root folder ng project bilang usecase-diagram-300dpi.png at usecase-diagram.drawio.
